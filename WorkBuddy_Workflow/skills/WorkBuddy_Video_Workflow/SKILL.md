# 视频制作通用工作流（WorkBuddy_Video_Workflow）

> **这份技能服务任何视频，不只代码渲染。** 开工第一件事是判类型（§0），不同类型走不同分支；但通用层（§1–§2）完全一样。
> 完整方法论见仓库 `WorkBuddy_Workflow/视频制作通用流程.md`；本文件是执行用的浓缩版，**判据与硬规则优先**。

## 0. 先判类型：五条分支

| 类型 | 典型场景 | 素材从哪来 | 单镜成本 | 分支 |
|---|---|---|---|---|
| **A 代码逐帧渲染** | 知识科普、数据解说、流程/结构/机械、抽象概念、角色动画 | 代码画（SVG/Canvas/Remotion） | **13~15 秒**（CPU） | §3 |
| **B AI 生成素材** | 实景感、真实人脸、自然风光、电影感空镜 | I2V/T2V 模型生成，再合成 | 25~30 分钟（GPU） | §4 |
| **C 真人实拍 / 口播** | 讲解、测评、vlog、访谈 | 手机/相机拍摄 | 取决于拍摄 | §5 |
| **D 剪辑混剪** | 影视解说、素材重组、二创 | 已有视频/图片 | 纯剪辑 | §6 |
| **E 图文轮播** | 观点输出、清单体、教程步骤 | 文字 + 图/截图 | 最快 | §7 |

**判据（按顺序问）**：

1. 这一镜**必须看起来像真的**吗？→ 是 → **B**（AI）或 **C**（实拍）
2. 有现成素材能剪吗？→ 是 → **D**
3. 信息是「结构 / 数据 / 流程」这类**几何关系本身就是信息**的吗？→ 是 → **A**
4. 只剩文字 + 图？→ **E**

⚠️ **默认选 A**：代码渲染参数可控、十几秒出片、可跨片复用；AI 单镜半小时且结果不可复现。
**"精致 ≠ 准确"**——结构类镜头 AI 的失败方式不是糊，是"似是而非"：说"三个半规管"，它给三根交叉细线，观众数不出三个。

**混合是常态**：一支片里 A 做图表、B 做空镜、C 做口播，合成时按同一份时间轴对齐即可。

## 1. 通用七步（所有类型都走）

| 步 | 做什么 | 产出 | 判据 |
|---|---|---|---|
| **1 定规格** | 平台 → 画幅、时长、帧率 | 一行参数 | 与投放位一致（§2.1） |
| **2 选题钩子** | 一句话说清"为什么看" | 标题 + 前 3 秒台词 | 3 秒内给反直觉（§2.2） |
| **3 分镜** | 一个信息点一个镜头 | 分镜表（镜号/时长/内容/字幕） | 无 >12s 长镜；时长求和精确（§2.3） |
| **4 出素材** | 按分支走 | 每镜画面 | 单镜预览通过 |
| **5 覆盖层** | 字幕、图文、角标 | 透明层或烧入 | 不压主体、不越安全区（§2.4） |
| **6 音频合成** | BGM + 音效 + 对齐 | 成片 | 音画等长、电平达标（§2.5） |
| **7 质检交付** | 三道闸门 + 三项自检 | 成片 + 封面 + 文案 | 全部通过（§2.6） |

**顺序不能反**：先定时长再找音乐，必然硬切或淡出点落在乐句中间；先做画面再想文案，必然返工重排。

## 2. 通用铁律（跨分支，违反必返工）

### 2.1 规格：画幅与平台

| 平台 | 正片 | 封面 |
|---|---|---|
| 抖音 / 视频号 / Reels | 竖版 9:16（1080×1920） | 横封面 **4:3**（1440×1080）+ 竖封面 **3:4**（1080×1440），**两套都要** |
| B站 / YouTube / 视频号横屏 | 横版 16:9（1920×1080） | 16:9 |
| 默认（本项目） | **横版 1920×1080 @24fps** | 见上 |

⚠️ **换画幅不是缩放，是重排版式**：竖版"上下堆叠"搬到横版会得到左右两片空白。开工先定三条水平线（横版：地平线 y≈760–800、字幕带 y≈880–1040、正文必须 y<780）。

### 2.2 选题与钩子：前 3 秒定生死

前两秒只有一句话的容量，用**结构化句式**而不是自由发挥：

| 环节 | 句式 | 作用 |
|---|---|---|
| 钩子 | 「明明只是……，怎么就……」 | 摆出日常经验，制造"我也遇到过" |
| 反转 | 「这不是……，是……」 | 一句话给因果，3 秒内兑现悬念 |
| 收尾 | 「愿你……」 | 从知识回到人，避免"讲完就断" |
| 系列化 | 「第 N 集｜系列名｜主题」+ 下集预告 | 同一批观众被下一集接住 |

- **结论前置**：抖音版第 0 帧就要给反直觉，不要铺垫。
- **长内容用"问题链"**：先列观众会问的 3~4 个问题，一幕答一个。内容多就**加镜头**，别压时长——压时长会压断因果链。
- **数字对撞**是最好的钩子：「53 年换 14 个皇帝，他凭什么让王朝活 319 年？」

### 2.3 分镜与时长：单一时间源

| 项 | 规则 |
|---|---|
| 节奏基准 | 有 BGM 用 BPM（每拍 = 60/BPM）；无 BGM 用固定镜头时长 |
| 分镜时长 | `拍数 × 每拍` —— 唯一公式，所有层都必须服从 |
| 全片 | **总拍数守恒**：Σ拍数 × 每拍 = 成片时长 = 音轨时长 |
| 镜头长度 | **无 >12s 长镜**；>12s 要配持续事件，否则必然"静止超时" |
| 信息密度 | 抖音知识类 1.5~3 秒一个视觉变化；每 2 秒一个新信息 |

**三条铁律**：① 改时间轴后必须重新生成派生文件（浏览器只读 js，不读 json）；② **拍数变了的镜头必须重建素材分段**，否则新旧错位；③ 所有层只认同一份时间轴，不要各自写死时间。

### 2.4 字幕与排版：唯一的安全区

- **统一走一个组件**：底部安全区 ~300px + "透明→深色"渐变底板 + 整块上移 ~90px 的 `easeOut` 淡入（按拍对齐，别逐字弹）。
- **主体让位**：正文限制在字幕带之上（横版 **y < 780**）。840 只够避开底板，人物头顶/道具顶端仍会探进字幕带。
- **落地靠扫描不靠眼**：出片前正则扫源码里所有 `y / cy / baseY` 落在 780–1080 的元素，逐个判断是背景（山脊/地面，可进）还是正文（人物/道具/文字，必须挪）。
- **先算单行容量**：中文全角 ≈ 1em，单行字数 ≈ 容器宽 ÷ 字号（留 5% 余量）。超了不报错，只把末尾两三个字挤成孤字行——**只能抽帧看**。修法：降一级字号 > 拆句 > 收窄内边距。
- **字数会变的元素要自适应字号**：印章、字牌、标签里放 2~6 个字，字号写死就会"两字撑满、六字溢出"。
- **文字可读性**：文字与素材分开开发时，"文字压亮部"只有合成后才暴露。素材有亮区（人脸/发光物）就加底衬或错位。

### 2.5 音频：BGM 是账号资产，不要每片现造

**先看母版有多长，再定内容量。** 能讲满就用满（母版自带淡出就是天然收尾）；只讲得一半，才退回"截取 + 尾部 `afade`"。

**成片比母版长，三种做法按优先级**：

| 方案 | 做法 | 何时用 |
|---|---|---|
| **延长剪辑**（首选） | 播到 E（避开尾部淡出）→ 4s **等功率交叉**接到曲中**相似段 S**（24 带能量向量余弦相似度，实测可到 0.9998）→ 续播 | 超过母版 1.5 倍，且能测出相似段 |
| 无缝循环 | 裁尾淡出 → 首尾 2~4s **等功率**交叉做环 → 铺满 → 片尾 3s 淡出 | 母版明显短、找不到相似段 |
| ❌ `-stream_loop` 硬接 | 尾淡出后突然满音量 | 永远别用 |

- **融合时长跟相似度走**：>0.999 时几十毫秒（40ms）就够，融合越长越像"两段同时在响"；相似度 <0.99 才给 2~4s。
- **等功率不是可选项**：线性权重在中点掉 ~3dB，听感就是"接点处音量塌一下"。
- **验收两条都要看**：接续区 0.5s 窗 RMS 跳变 <4dB **且** 频谱跳变 <1.4× 全片均值。只看总电平发现不了接点。
- **混流用 `-t <成片时长>` 精确截断，不加 `-shortest`**（会裁尾帧）。
- **音效可纯代码合成**（振荡器 + 包络，numpy 就够）：按画面事件对齐（与画面共用同一份时间轴），权重约 0.55 叠在 BGM 上，**混完重新过电平判据**——音效会把峰值顶高。
- **电平**：mean ≈ −15dB，峰值留 ≥1dB 余量。触顶就是削波，听感是"炸音"而频谱图上看着还正常。

### 2.6 质检：三道闸门 + 三项自检

| 闸门 | 判据 | 时机 |
|---|---|---|
| ① 单镜 | 无报错；排版不压主体；文字与底板亮部对比度够；时序对得上 | 每次改画面 |
| ② 节奏 | **最长连续冻结 ≤3.0s**（低阈值均值差 <0.002 灰度记冻结）；静止占比 >45% 需检查 | 合成后 |
| ③ 成片 | 音画时长严丝合缝；关键帧像素特征；音频 mean≈−15dB 且峰值不触顶 | 交付前 |

**出片前三项自检**（自动闸门验不到）：

| 自检 | 抓什么 |
|---|---|
| 空白帧扫描（每 ~12s 抽一帧算方差） | 漏渲 / 透明层没叠上的全黑或纯色帧（刻意的起幅黑场单列） |
| 元文字未上屏（搜"机制说明/系列标签/制作标注"） | 草稿期写给人看的字上了屏——图表机制说明、"第 N 集"是高频漏项 |
| 逐幕坐标求交（文字块 x/y/宽/高 两两求交） | 跨块重叠（图例压地名、角标压标题） |

**判据只测"有没有变化"，不测"好不好看"**：

- 它先下采样（分析尺度常 270px 宽），**柔光呼吸/渐变明暗会被采样抹平**——像素差 <6 灰度，数值上零运动，人眼却觉得"在呼吸"。这是**伪运动**，救不了判据。
- 有效的是**画面实体的硬边动作**（旗/火苗/狼烟/驿马/宫灯/蒸汽，逐帧位移 ≥2px）、高对比长线条扫过、大面积高幅度位移。
- ⚠️ **别用抽象背景粒子"点点"凑运动**：推得动判据，但观感廉价，用户会判"背景在飘"。运动要长在**画面里存在的东西**上。
- **通过 ≠ 观感好**（花哨廉价的运动也能过）；**不通过 ≠ 难看**（收尾定格本该静）。
- 任何单一数值指标都要与人眼抽帧交叉验证。

### 2.7 封面与发布

| 项 | 做法 | 为什么 |
|---|---|---|
| 封面版式 | 参数化（宽高走参数），一套模板渲多尺寸；出图用渲染器**单帧命令** | 各平台各做一版必然逐渐不一致 |
| 封面底图 | 从**素材层**抽帧，不从成片抽 | 成片已烧入字幕，抽帧带文字残影 |
| 主视觉 | **一眼能辨认是什么**；缩小到 200px 宽还认得出 | 信息流里就是这个尺寸 |
| 光效 | 同心细环 + 径向柔光 | 粗放射条在深底上叠出灰褐色，像玻璃裂纹 |
| AI 标注 | 画面含 AI 生成内容就标注 | 只勾"原创"不标注有限流/下架风险 |

**发布：半自动填表，发布键留给人**（平台无个人开放 API）。脚本做上传/标题/简介/话题，人做登录、自主声明、合集、点发布。

**六个必知的坑**：① 扫码后跳首页，找不到控件要重新 `goto` ② 用 `networkidle2`，`domcontentloaded` 太早 ③ **话题上限 5 个** ④ **脚本退出会关浏览器、表单全丢** → 结尾 `setInterval` 常驻 ⑤ **封面「保存」用合成事件会静默失败**（存成黑场首帧且不报错）→ 必须真实 `locator.click()` ⑥ **话题写成纯文本不转 chip** → 必须键盘输入触发下拉再点选。

**数据回流看「2 秒跳出率」，不看播放量**：播放量由推荐量决定。实测基线 45~50%；改版后 <30% 说明钩子有效，仍在 45% 左右说明问题在选题或封面承诺。**发布后等 2 小时再读**。

## 3. 分支 A · 代码逐帧渲染（默认）

**完整手册见 [`references/branch-A-code-render.md`](./references/branch-A-code-render.md)**，这里只给骨架。

**核心**：所有动画是时间 `lt` 的纯函数，任意一帧可复现、可定位、可对比。三层分离：素材层 + 覆盖层（透明）+ 音轨，各自生成后一次性合成。

**八步**：定节奏 → 概念首帧 → 生成素材 → 建素材层 → 做覆盖层 → 单镜预览 → 合成 → 质检交付。

**渲染五条硬规则**（违反必出 bug）：

1. 禁止 CSS `transition` / `keyframes`（逐帧 seek 会抖）
2. 禁止 `Math.random()`（每帧重算会跳，用确定性 `rng(seed)`）
3. 禁止 `background-clip:text`（无头 Chrome 丢渐变填充，字变透明）
4. 带样式的原子标签不可拆字
5. 慢放素材要与动画同步（`lt /= K`）

**工程两条**：单镜样式必须 `#sN` 限定；绝对定位块必须算垂直占位。

**两个必查**：① 预览工具先自检（看不见底板特征 = 叠加链路断了，看到的"干净画面"是假的）② 改组件内部变量后**立刻全局搜旧名**（漏引用只在特定帧崩，小样查不出来）。

**视觉基线**：插画感剪影 + 丰富动效，不是扁平简笔。场景靠**层次**立住（多层视差、光渐变），关键节点给大动作（数字砸屏、披袍、盖章）。

## 4. 分支 B · AI 生成素材（I2V / T2V）

**只在 A 做不出来时用**：实景感、真实人脸、车内实拍、自然风光、电影感空镜。

**流程**：概念首帧（图像生成）→ I2V 生成视频 → 建素材层（调色/裁切/定速）→ 与覆盖层合成。

**提示词四查**：细节充分 / 契合功能 / 同向概念帧 / 区别于他镜。

**必带运动**：不写 "completely still"；写慢眨眼、呼吸、光效明灭、极缓推近。静止素材必然触发节奏缺陷。

**运动镜头的三条物理约束**（载具/跟拍必查）：

| 约束 | 要写清什么 | 反例 |
|---|---|---|
| 视角 | 相机相对载具的朝向，并排除错误视角 | 只写 "side window" → 漂成前方路面视角 |
| 车姿 | 车身姿态变化**对窗外画面的后果**（横滚→地平线倾斜几度） | 只写 "car leans into a curve"，不写后果 |
| 轨迹 | 沿道路切线；入弯时近景摆向车身；景物通过角度**不是固定一个角度** | 全程 `streak past horizontally` = 假设永远直行 |

外加：**相机刚性固定**（写 `swaying with the suspension` 就是主动要求颠簸）；**车内固定参照物**（窗框/头枕相对镜头不动，是让观众读懂"外面在动"的锚点）。

**无人值守队列三条铁律**：① **排队 ≠ 执行**（超时只算正在执行的时间）② **判失败前先查磁盘**（直接重试 = 同一条 GPU 活干两遍）③ **提交前先查队列和共享输出目录**。

**卡死 ≠ 慢**：长时间占 running 无产出 + `/history` 返回空 + `interrupt` 无效 → 三条同时成立才是卡死，要重启（属破坏性操作，须先征得同意）。

**负面词必须随题材重审**：负面词带题材假设（解剖片不能用 `cgi/3d render/bioluminescence`），按镜头类型分套路由。

## 5. 分支 C · 真人实拍 / 口播

**声音质量 > 画质**。观众能忍画面糊，忍不了声音闷。

| 环节 | 要点 |
|---|---|
| **收音** | 领夹麦优先；室内选小房间（少混响）、挂毯/衣柜前录；手机录音要离嘴 15~20cm |
| **拍摄** | 固定机位、眼平高度、光从正面 45°（窗光 + 补光板就够）；竖版留头部空间，横版留字幕带 |
| **稿子** | 逐字稿 + 提词器；**句子写短**（口播一句 ≤15 字），长句必卡 |
| **节奏** | 每 3~5 秒一个信息点；说错不重来，停顿 1 秒接着说，剪辑时删停顿 |
| **剪辑** | 跳剪去气口/口误 → B-roll 覆盖空档 → 字幕自动生成后**逐字校对**（专有名词必错） |
| **字幕** | 自动识别只作初稿；数字、人名、术语必须人工核 |

**与通用层的衔接**：口播片的"分镜"= 段落划分（每段一个论点）；"覆盖层"= 字幕 + 关键词条 + B-roll 角标；质检同样是"最长静止 ≤3s"——**固定机位讲话超过 3 秒没画面变化就要插 B-roll 或推近**。

## 6. 分支 D · 剪辑混剪

**适用**：影视解说、素材重组、二创、盘点。

| 环节 | 要点 |
|---|---|
| **素材整理** | 按主题/情绪打标签，先粗剪出"素材池"，再按脚本取用 |
| **结构** | 钩子 3s（最反直觉的画面）→ 论点 → 论据（素材支撑）→ 收尾回扣 |
| **节奏** | 抖音知识类 1.5~3 秒一个画面变化；长镜头必须有事发生 |
| **音频** | 原声压低到 −25dB 以下当底噪，BGM 主导；关键台词处 BGM 让位（ducking） |
| **版权** | 二创要有**实质改动**（解说/重组/加观点），纯搬运会被判非原创 |

**与通用层的衔接**：混剪的"分镜"直接就是剪辑点列表；质检用同一套"最长静止 ≤3s"，但注意**固定画面的解说段落**要配字幕动效或推拉，否则数值会报警（这里报警是对的）。

## 7. 分支 E · 图文轮播

**最快出片的一类**，适合观点输出、清单体、教程步骤。

| 项 | 规则 |
|---|---|
| **一页一个信息点** | 一页塞两个观点，观众一个都记不住 |
| **字号** | 手机上正文 ≥40px（1080 宽画布）；标题 ≥90px |
| **页数** | 6~12 页；少于 6 页信息量不够，多于 12 页完播率断崖 |
| **单页停留** | 2~3 秒（按字数算：字数 ÷ 8 秒） |
| **首图** | 就是封面，必须独立成立（信息流里只露这一张） |
| **末页** | 收尾句 + 关注引导，别放"谢谢观看" |

**与通用层的衔接**：图文轮播的"覆盖层"就是全部内容，没有素材层；质检重点从"有没有动"转为**每页停留时长是否够读完**（字数 ÷ 阅读速度 8 字/秒）。

## 8. 踩坑速查（跨分支高频）

| 症状 | 根因 | 规则 |
|---|---|---|
| 字幕压画面主体 | 逐镜手摆，没有统一安全区 | 统一组件 + 主体 **y<780**（§2.4） |
| 字幕被平台 UI 压住 | 安全区按"看起来够"给的 | 底部留 ~300px（§2.4） |
| 长句末尾两三个字单独成行 | 字数×字号 > 容器宽，超了不报错只折行 | 单行字数 ≈ 容器宽÷字号（§2.4） |
| 文字压亮部看不清，自动判据全过 | 对比度不在任何判据里 | 排版前看底板亮度，亮区加底衬/错位 |
| 加一堆小动效，静止判据只降 2% | 判据算全画面平均差，小元素贡献 <0.0005 | 用大面积/高对比；或改镜头长度 |
| 柔光呼吸加了没效果 | 下采样后软过渡被抹平，是**伪运动** | 用画面实体的硬边动作（§2.6） |
| 满屏粒子在飘，被判"背景在动" | 用抽象粒子凑运动量 | 运动长在画面实体上（§2.6） |
| 深色底的活镜头被判"静止 3s 以上" | 阈值给太宽（1.5/255），大片静止区稀释局部动画 | 阈值压到 **0.002 灰度**（§2.6） |
| 缓慢微摆被判冻结，抽帧看明明在动 | 用了"变化像素占比 0.3%"，大面积慢移单像素变化不到 6 灰度 | 改用低阈值均值差（§2.6） |
| 17s 镜头怎么加动效都闷 | 镜头太长 + 素材静态 | >12s 必须配持续事件，或缩短（§2.3） |
| 循环 BGM 接点"断一下" | `-stream_loop` 硬接母版 | 延长剪辑或等功率环（§2.5） |
| 循环做了，接点仍"塌一下" | 交叉淡化用线性权重，中点掉 3dB | 等功率 `sqrt` 曲线（§2.5） |
| 加了音效后成片削波 | 只验 BGM 电平 | 混完重新过电平判据（§2.5） |
| 每支片 BGM 听感都不一样 | 为每片临时合成新曲 | 用既定母版（§2.5） |
| 封面上的字与底图上的字叠在一起 | 底图从**成片**抽帧 | 只从素材层抽（§2.7） |
| 封面图形认不出是什么 | 用直线围个轮廓就当"物件" | 画出可辨识的结构（肩/袖/下摆） |
| 发布后被判非原创/限流 | AI 画面只勾"原创"没标 AI | 按平台要求标注（§2.7） |
| 填好的表单突然全丢 | 脚本进程退出，浏览器一起关 | `setInterval` 常驻（§2.7） |
| 话题标签没生效 | 写成纯文本，没走下拉选中 | 键盘输入 + 点选（§2.7） |
| 数据看着很差但刚发布 | 冷启动前 30 分钟波动极大 | 等 2 小时看 2 秒跳出率（§2.7） |

> 代码渲染专属的 40+ 条坑（渲染/合成/时间轴/AI 队列）见 [`references/branch-A-code-render.md`](./references/branch-A-code-render.md)。

## 10. Checklist

### 通用（任何视频）

```
□ 定平台 → 画幅/时长/帧率；封面按平台要几套
□ 钩子：第 0 帧给反直觉；标题能独立成立
□ 分镜表：一镜一信息点；无 >12s 长镜；时长求和精确
□ 时长与 BGM 母版对齐（等长 / 截取 / 延长剪辑，不用 -stream_loop）
□ 字幕统一组件；正文 y<780；单行字数 ≤ 容器宽÷字号
□ 封面：参数化模板；底图从素材层抽；主视觉缩小仍可辨
□ 三道闸门：单镜预览 → 最长冻结 ≤3s → 音画等长 + 电平
□ 三项自检：空白帧 / 元文字 / 逐幕坐标求交
□ 抽帧人眼过 2 轮（自动判据抓不到"断字/结构错/难看"）
□ 发布物料齐备：标题、简介、5 个话题、封面、AI 标注
□ 发布键留给人；发后 2 小时再看 2 秒跳出率
```

### 分支 A 追加（代码渲染）

```
□ 时间轴改完重生成派生文件；改拍数必须重建该镜素材
□ 预览工具先自检（能看见底板特征）
□ 覆盖层新建框架，不照抄旧片
□ 渲染五条硬规则逐条过；单镜样式带 #sN
□ 改组件变量后全局搜旧名
□ 先渲 0-12 帧小样，确认组件引用完整
□ 排版后做垂直占位核算 + 字数核算
□ 环境动效用画面实体，不用柔光呼吸/背景粒子
□ 改完一处做差分定位（差异量 ≈ 改动面积，无关区 0%）
```

### 分支 B 追加（AI 素材）

```
□ 先问"能不能代码做"，不能才用 AI
□ 负面词按题材重审；按镜头类型分套
□ 运动镜头三约束（视角/车姿/轨迹）+ 相机刚性固定
□ 队列：超时只算执行时间；判失败前先查盘；提交前查队列
□ 生成完立刻粗筛，别等成片
```

### 分支 C / D / E 追加

```
□ C：先测收音（比画质重要）；逐字稿；字幕人工校对专有名词
□ D：素材打标签；原声压到 −25dB 以下；二创要有实质改动
□ E：一页一信息点；正文 ≥40px；6~12 页；首图独立成立
```
