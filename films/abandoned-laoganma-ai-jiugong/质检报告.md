# 《老干妈 AI 裁员？》质检报告

质检对象：`out/老干妈AI裁员辟谣.mp4`（1080×1920 / 24fps / 876 帧 / 36.5s）
质检工具：`remotion/qc.py`（灰度 rawvideo 逐帧分析）+ `ffmpeg volumedetect` + 多模态人眼抽帧

## 1. 节奏体检（硬指标：最长静止 ≤ 3s）

| 指标 | 结果 | 判定 |
|---|---|---|
| 总帧数 | 876（24fps × 36.5s，与设计一致） | ✅ |
| 最长静止 run | **67 帧 = 2.79s**（起于第 586 帧，S8 风险条形图铺满后段） | ✅ < 3s |
| 第二长静止 run | 58 帧 = 2.42s（起于第 91 帧，S2 盖章后） | ✅ |
| 变化像素占比阈值 | 0.3%（真冻结才会低于此值） | — |

> 上一版用「全帧平均灰度差」判定，在深色背景下会把传送带、计数滚动这类**局部动画**误判为静止（曾误报 3.46s）。改为**变化像素占比**后，指标恢复真实含义。判定阈值同时经过人眼抽帧校验：被标记为静止的区间，画面确无实质变化。

## 2. 亮度抽检（排除全黑 / 全白 / 空画面）

| 指标 | 值 |
|---|---|
| 逐帧平均亮度 min | 16.3 / 255 |
| 逐帧平均亮度 max | 23.8 / 255 |
| 全片平均亮度 | 20.0 / 255 |

全片为深色主题，亮度区间窄且稳定在 16–24，**无全黑帧、无全白帧、无空画面**。

## 3. 场景切换检测

变化像素占比 > 5% 处自动识别出切点：**149 / 233 / 317 / 569 / 821** 帧，
与设计的时间轴边界（S3→S4→S5→S9→S11）**完全吻合**，证明 11 镜严格按 Sequence 排布、无错帧、无漏帧。

## 4. 音频

| 指标 | 值 | 判定 |
|---|---|---|
| 音轨 | AAC-LC 44100Hz 立体声 199 kbps | ✅ |
| mean_volume | **−15.9 dB** | ✅ 正中目标区间（≈ −15dB） |
| max_volume | **−6.4 dB** | ✅ 有 6dB 余量，无削波 |
| 音画时长 | 视频 36.50s / 音频 36.50s | ✅ 一致 |

BGM 使用工作流既定曲目 `bgm_final.m4a`（与 `out/audio/bgm_final.m4a` 136.7s 母版同源，前 40s 频谱质心相关系数 1.000），与账号此前作品听觉统一。源文件 40s 自带结尾淡出在 38–40s，视频截断至 36.5s 处音乐仍在进行中，故混流时补 `afade=out:st=35.3:d=1.2` 自定义淡出，并预留 `volume=-1dB` 编码余量。

## 5. 人眼抽帧（多模态逐帧核验）

抽取 6 个分镜关键帧（1.375s / 4.5s / 8.0s / 11.5s / 22.0s / 35.375s）逐张核验：

| 抽帧 | 核验结论 |
|---|---|
| S1 钩子 | ✅ 「老干妈用 AI 裁掉 552 人？」完整无换行断裂，红色辉光生效，「先别急着转」在位 |
| S2 辟谣 | ✅ 盖章「辟谣 不实」旋转角度与缩放正常，红色描边 + 辉光清晰，信源行在位 |
| S3 营收 | ✅ 数字滚动中（30 亿），「亿」字号与主数字比例正确 |
| S4 分拣线 | ✅ 传送带辣椒流动、机械臂摆动、「分拣」框均在位，「自动化 ≠ 裁员」在位 |
| S7 金句 | ✅ 三行大字层级清晰，末句「不是『岗位』」红色强调生效 |
| S11 结尾 | ✅ 罐子图形完整（红标/辣椒图标/瓶盖），结论与信源在位；底部关注引导处于淡入末段，属动画中间态，非缺失 |

**无文字溢出、无元素重叠、无字体缺字（豆腐块）、无空白画面。**

## 6. 硬规则合规自查

| 规则 | 结果 |
|---|---|
| 禁 CSS `transition` / `@keyframes` | ✅ 全片零使用 |
| 禁 `Math.random` | ✅ 动画全部为帧号确定性函数；BGM 噪声用固定随机种子 |
| 禁 `background-clip:text` | ✅ 大字辉光改用 `textShadow` |
| 单镜样式限定 | ✅ 每镜独立组件，样式不跨镜泄漏 |
| 垂直占位核算 | ✅ 6 镜抽帧确认无越界/重叠 |
| 逐字动画样式挂每字 | ✅ 本片无逐字动画（未使用该模式） |
| 混流不加 `-shortest` | ✅ 用 `-t 36.5` 精确截断，音画等长 |

## 7. 结论

**通过。** 成片可直接进入发布环节，无需返工。

待人工确认项（不影响成片可用性）：
1. 抖音发布时是否需要加平台水印/片尾标，取决于账号运营策略。
2. BGM 为纯音乐无配音——若账号以口播为主，可另配 TTS；本片本身是「字幕即文案」的知识科普体例，无需配音。
