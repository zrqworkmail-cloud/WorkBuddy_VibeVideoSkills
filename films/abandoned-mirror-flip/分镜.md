# 《镜子的左右之谜》分镜脚本

**成片**：`out/镜子的左右之谜.mp4` ｜ 1080×1920 竖屏 ｜ 24fps ｜ 876 帧 ｜ **36.5 秒**
**封面**：`out/cover.png` ｜ 1080×1920（9:16 满屏）
**BGM**：`out/bgm.m4a` ｜ 工作流既定曲目 `bgm_final.m4a`（40s 版）｜ 截断至 36.5s + 1.2s 淡出

## 选题说明

**一般性知识科普**（按选题红线：不涉及企业/品牌/时事）。题材为经典物理知觉问题：

> 你对着镜子举起右手，镜中的「你」举起的却是「左手」。上下从来不反，偏偏左右反——为什么？

选它的三个理由：① 强反直觉钩子，人人天天照镜子却几乎没人想对过；② 解答是纯几何概念（镜像 = 沿镜面法线的前后翻转），所有演示都能用 SVG 图形确定性画出；③ 带三个在家可复现的实验 + 一个生活应用（救护车反字），干货密度够。

## 核心论证链（结论前置）

1. **答案先行**：镜子只翻转一个方向——垂直于镜面的「前后」。
2. 实验一：看上下——头还是头、脚还是脚，上下没被翻。
3. 实验二：俯视图看前后——你指向镜子的手，镜中的像反指回来；被翻的只有前后。
4. 关键一步：你面对镜子时必须**绕「上下轴」转身 180°**，转身这一下你的左右互换了位置——「左右相反」是你自己转出来的。
5. 反证：换个轴（头朝前翻过去面对镜子），反的就变成上下——证明翻转感受取决于你的转轴，与镜子无关。
6. 实验三：透明纸写「F」举到镜前——镜中的字和你「把纸翻过来从背面看」一模一样，翻纸=转身。
7. 生活应用：救护车车身印反字，前车后视镜（平面镜）翻转前后后刚好读成正字。
8. 方法论收口：遇到反直觉，先问「参照物换了吗」。

## 制作约束（全程纯代码）

- **零 AI 视频生成、零本地权重**。画面 100% 由 Remotion（React + SVG）按 `useCurrentFrame()` 计算得出；音乐用工作流既定 BGM。
- 七条硬规则：禁 CSS `transition`/`keyframes`、禁 `Math.random`、禁 `background-clip:text`、单镜独立组件限定样式、绝对定位块垂直占位核算、逐行文字宽度核算。
- S5 的转身动画 = 确定性插值（`interpolate` 180°→0°），S7/S9 的反字 = 确定性 `scaleX(-1)`，均为纯时间函数。

## 复现方式

```bash
cd reference/remotion
export CHROME_EXECUTABLE_PATH="/c/Users/Admin/AppData/Local/ms-playwright/chromium-1234/chrome-win64/chrome.exe"
export CHROME_HEADLESS=true
./node_modules/.bin/remotion render src/index.ts Mirror out/mirror_silent.mp4 --overwrite
# 混流：既定 BGM，-t 精确截断（不用 -shortest），截断处补 1.2s 淡出
<ffmpeg> -i out/mirror_silent.mp4 -i films/yunche-45s/out/audio/bgm_final.m4a \
        -af "volume=-1dB,afade=t=out:st=35.3:d=1.2" \
        -c:v libx264 -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -t 36.5 \
        -movflags +faststart out/mirror_final.mp4
# 封面
./node_modules/.bin/remotion still src/index.ts MirrorCover out/mirror_cover.png --overwrite
```

源代码：`../../remotion/src/Mirror.tsx`（分镜+动画）、`../../remotion/src/MirrorCover.tsx`（封面）、`../../remotion/qc.py`（质检）。
