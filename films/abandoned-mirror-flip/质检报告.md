# 《镜子的左右之谜》质检报告

质检对象：`out/镜子的左右之谜.mp4`（1080×1920 / 24fps / 876 帧 / 36.5s）
质检工具：`remotion/qc.py`（灰度 rawvideo 逐帧分析，变化像素占比法）+ `ffmpeg volumedetect`

> 本会话模型不支持图像核验（多模态不可用），画面内容以量化指标 + 布局占位核算代替人眼抽帧；发布前建议人工快看一遍 S3/S5/S7 三个图形镜头。

## 1. 节奏体检（硬指标：最长静止 ≤ 3s）

| 指标 | 结果 | 判定 |
|---|---|---|
| 总帧数 | 876（24fps × 36.5s，与设计一致） | ✅ |
| 最长静止 run | **53 帧 = 2.21s**（起于第 96 帧，S2 结论字就位后段） | ✅ < 3s |
| 其余较长静止 | 29 帧=1.21s（204 帧，S3 箭头亮起后）、24 帧=1.0s（166 帧） | ✅ |
| 变化像素占比阈值 | 0.3%（真冻结才会低于此值） | — |

## 2. 亮度抽检（排除全黑 / 全白 / 空画面）

| 指标 | 值 |
|---|---|
| 逐帧平均亮度 min | 18.0 / 255 |
| 逐帧平均亮度 max | 28.6 / 255 |
| 全片平均亮度 | 23.0 / 255 |

深色主题下亮度稳定在 18–29，且比上一支片（16–24）略高——SVG 图形镜头（S3–S6、S11）带来了更多画面元素占比。**无全黑帧、无全白帧、无空画面。**

## 3. 场景切换检测

变化像素占比 > 5% 处自动识别出切点：**65 / 149 / 233 / 317 / 401 / 485 / 569 / 737 / 821** 帧，
与 11 镜 Sequence 边界（66/150/234/318/402/486/570/738/822，差分索引偏移 1）**全部吻合**。
其中 80–82 帧的额外切点为 S2 真相卡盖章（spring 弹入）的运动峰值，属正常动画。S8→S9（654 帧）未触发 5% 阈值：两镜均为居中大字版式，背景亮度接近，属版式相似而非丢帧——上下镜内容不同，不构成问题。

## 4. 音频

| 指标 | 值 | 判定 |
|---|---|---|
| 音轨 | AAC-LC 44100Hz 立体声 199 kbps | ✅ |
| mean_volume | **−15.9 dB** | ✅ 正中目标区间（≈ −15dB） |
| max_volume | **−6.4 dB** | ✅ 有 6dB 余量，无削波 |
| 音画时长 | 视频 36.50s / 音频 36.50s | ✅ 一致 |

BGM 使用工作流既定曲目 `bgm_final.m4a`（40s 版，与母版同源）。源文件自带淡出在 38–40s 会被 36.5s 截断，故补 `afade=out:st=35.3:d=1.2` 自定义淡出 + `volume=-1dB` 编码余量。

## 5. 硬规则合规自查

| 规则 | 结果 |
|---|---|
| 禁 CSS `transition` / `@keyframes` | ✅ 全片零使用 |
| 禁 `Math.random` | ✅ 全部为帧号确定性函数（interpolate / spring / 正弦呼吸） |
| 禁 `background-clip:text` | ✅ 大字辉光用 `textShadow` |
| 单镜样式限定 | ✅ S1–S11 独立组件，样式不跨镜泄漏 |
| 垂直占位核算 | ✅ 文本块均在安全区（顶部 13%/12% 起，底部 100–130px 收口）；S3 SVG 高 900px 从 y=420 起（底至 1320 + 镜底标注 40px，不压底部文案）；S4 760px 从 480 起；S5 720px 从 470 起；S6 面板从 430 起、双列 flex 布局 |
| 文字宽度核算 | ✅ 最大行 96px 字号 × 9 字 ≈ 864px < 1080−128 安全区 |
| 逐字动画样式挂每字 | ✅ 本片无逐字动画 |
| 混流不加 `-shortest` | ✅ 用 `-t 36.5` 精确截断，音画等长 |
| BGM 用既定曲目 | ✅ `bgm_final.m4a`，非自合成 |

## 6. 内容正确性核查（知识类成片必查）

- 论证链：镜像 = 沿镜面法线（前后）翻转；「左右相反」源于观察者绕竖直轴转身 180° 的自我旋转——**表述准确**。
- 反证实验（换转轴则反上下）符合几何事实；「F」透明纸实验与「翻纸=转身」类比成立。
- AMBULANCE 反字案例：车身镜像书写使前车后视镜中读成正字，**事实正确**。

## 7. 结论

**通过。** 成片可直接发布。遗留人工项：发布前人眼快看 S3（火柴人照镜）、S5（转身动画）、S7（反字）三个图形镜头的观感；本会话无法看图，指标层面无异常。
