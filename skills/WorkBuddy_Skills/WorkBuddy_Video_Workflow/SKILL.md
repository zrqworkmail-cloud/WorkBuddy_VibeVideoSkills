# 视频制作流程 · 从选题到提交

> **这份流程与项目、工具、素材来源都无关。** 换题材、换工具、换平台，阶段顺序不变，只是每个阶段的实现方式变。
> 全文主线是 8 个阶段，每个阶段给「做什么 / 判据 / 常见错误」。判据是验收线，不达标不进下一阶段——问题滚到成片才发现，返工成本是十倍。

```
选题 → 脚本 → 分镜 → 素材 → 剪辑合成 → 质检 → 交付 → 发布复盘
```

---

## 阶段 0 · 选题

**做什么**：决定"讲什么"，以及"凭什么有人看"。

**三条选题来源**（按命中率排序）：

| 来源 | 怎么找 | 特点 |
|---|---|---|
| **反直觉的日常** | 天天见、但从没想过为什么的事（镜子为什么左右反） | 最稳：人人有共鸣，钩子天然成立 |
| **认知缺口** | 大众知道结论、不知道机制的事（历史事件的真实条件） | 信息增量大，适合长视频 |
| **强对比数字** | 两个悬殊的数字并置（53 年 14 帝 vs 319 年 18 帝） | 适合开头砸屏，但需要内容撑住 |

**选题四问**（四问都过才立项）：

1. **谁看？** 说得出具体人群，不是"所有人"
2. **为什么看？** 一句话说清"他能得到什么"（新知 / 情绪 / 谈资）
3. **凭什么信？** 有没有可核查的依据（数据、史料、原理）
4. **看完做什么？** 转发 / 收藏 / 评论——三者至少占一个

**常见错误**：

- ❌ 题目正确但无趣（"如何保持健康"）→ 必须有一个具体的反直觉切口
- ❌ 蹭热点但没增量（大家都知道的事再说一遍）
- ❌ 需要长铺垫才成立（前 3 秒给不出钩子，抖音直接划走）

**红线**：不碰政治敏感、不点名企业/品牌做负面、不做需要专业资质的断言（医疗/法律/投资建议）。

## 阶段 1 · 脚本

**做什么**：把选题写成"念出来能听"的话，定好结构与时长。

### 1.1 开头：前 3 秒定生死

前两秒只有一句话的容量。用**结构化句式**，不要自由发挥：

| 环节 | 句式 | 作用 |
|---|---|---|
| 钩子 | 「明明只是……，怎么就……」 | 摆出日常经验，制造"我也遇到过" |
| 反转 | 「这不是……，是……」 | 一句话给因果，3 秒内兑现悬念 |
| 收尾 | 「愿你……」 | 从知识回到人，避免"讲完就断" |
| 系列化 | 「第 N 集｜系列名｜主题」+ 下集预告 | 同一批观众被下一集接住 |

**数字对撞**是最省力的钩子：「53 年换了 14 个皇帝，他凭什么让王朝活 319 年？」

### 1.2 中段：三种结构，按内容量选

| 结构 | 适用 | 骨架 |
|---|---|---|
| **问题链** | 知识科普（长） | 列观众会问的 3~4 个问题，一幕答一个，幕间用"回答上一问引出的下一问"衔接 |
| **结论前置** | 观点输出（短） | 第 0 帧给结论 → 三个论据 → 回扣 |
| **故事弧** | 历史/事件 | 铺垫 → 冲突 → 转折 → 收束 |

⚠️ **内容多就加镜头，别压时长**。压时长会压断因果链，观众只记住结论、不记住推理——而"推理过程"才是他愿意转发的理由。

### 1.3 时长：先定总长，再分配

| 平台 | 常规时长 | 单镜长度 |
|---|---|---|
| 抖音知识类 | 30~60s（长内容可 2~4 分钟） | 2~8s |
| B站/YouTube | 3~15 分钟 | 5~15s |
| 视频号 | 30~90s | 3~8s |

**判据**：脚本**念一遍计时**（正常语速 4~5 字/秒），误差控制在 ±10%。不要用"感觉大概两分钟"。

### 1.4 脚本自检

- □ 第一句能不能独立当标题用
- □ 每段开头有没有"所以呢"的钩子（避免"然后……然后……"）
- □ 数字/人名/年代逐个核对过来源
- □ 念一遍不顺口的句子全部改短（口播一句 ≤15 字）

## 阶段 2 · 分镜

**做什么**：把脚本切成镜头，每个镜头定"画面 + 时长 + 字幕"。

### 2.1 三条硬规则

| 规则 | 说明 |
|---|---|
| **一镜一信息点** | 一个镜头塞两个观点，观众一个都记不住 |
| **无 >12s 长镜** | 超过 12 秒必须配持续事件，否则画面必然"死"；宁可拆成两镜 |
| **时长求和精确** | Σ镜头时长 = 成片时长 = 音轨时长，三者必须严丝合缝 |

**判据**：分镜表列出来后，**逐行加总**核对一次。手算错一位数，后面全部错位。

### 2.2 画面设计三问（每个镜头都要答）

1. **这一镜的信息是什么？**（一句话，答不出就是废镜）
2. **画面怎么承载它？**（图形/实景/文字/人物动作）
3. **观众看哪里？**（视觉焦点在哪，字幕会不会压住它）

### 2.3 分镜表字段

```
镜号 | 时长 | 画面内容 | 画面承载物 | 字幕/旁白 | 素材来源 | 备注
```

**「画面承载物」这一列是防返工的关键**：每条字幕/旁白，画面里得有一个**具体的东西**在承载它。填不出来的，就是"只有文字没有画面"——观众会觉得在听 PPT。

| 不合格 | 合格 |
|---|---|
| 字幕：「主少国疑，权力真空」→ 画面：延续上一镜的宫殿 | 空龙椅 + 7 岁幼帝坐在椅上 + 太后在侧 + 大臣窃语 |
| 字幕：「只差有人去拧」→ 画面：还是那把锁 | 钥匙插入锁孔 → 转动 → 金光开锁（单独一镜） |
| 字幕：「殿前都点检是禁军最高统帅」→ 画面：一个印章 | 五位开国皇帝快速闪过 + 禁军阵列 + 兵符 + 点检印 |

⚠️ 抽象名词必须**落地成场景**，比喻句**单独成镜**。这条没做，后面所有画面工作都是在给 PPT 配图。

**「素材来源」**这一列决定阶段 3 怎么走，先标清楚再开工。

## 阶段 3 · 素材

**做什么**：把每个镜头需要的东西生产出来。**这一步是唯一随项目变化的阶段**，其余阶段都一样。

### 3.1 五条路径，按需选（可混用）

| 路径 | 适用镜头 | 成本量级 | 什么时候选 |
|---|---|---|---|
| **A 代码渲染** | 结构/数据/流程/抽象概念/角色动画 | 单镜十几秒（CPU） | **默认**：几何关系本身就是信息时 |
| **B AI 生成** | 实景感、真实人脸、自然风光、电影感空镜 | 单镜几十分钟（GPU） | 只有代码确实做不出来时 |
| **C 真人实拍** | 讲解、测评、访谈、vlog | 取决于拍摄 | 需要真实的人/信任感时 |
| **D 剪辑混剪** | 影视解说、素材重组、二创 | 纯剪辑 | 有现成素材时 |
| **E 图文轮播** | 观点、清单、教程步骤 | 最快 | 信息本身就是文字时 |

**判断顺序**（按这个顺序问，别跳）：

1. 这一镜**必须看起来像真的**吗？→ 是 → B 或 C
2. 有现成素材能剪吗？→ 是 → D
3. 信息是「结构 / 数据 / 流程」这类**几何关系本身就是信息**的吗？→ 是 → A
4. 只剩文字 + 图？→ E

⚠️ **"精致 ≠ 准确"**：结构类镜头用 AI 的失败方式不是糊，是"似是而非"——说"三个半规管"，它给三根交叉细线，观众数不出三个。

**混合是常态**：一支片里 A 做图表、B 做空镜、C 做口播，合成时按同一份时间轴对齐。

### 3.2 各路径的要点

**A 代码渲染**：所有动画写成时间的纯函数，任意一帧可复现。五条硬规则：不用 CSS transition（逐帧 seek 会抖）、不用随机数（每帧重算会跳）、不用 `background-clip:text`（无头浏览器丢填充）、带样式的原子标签不拆字、慢放素材要同步压缩动画时间。

**B AI 生成**：提示词四查（细节充分 / 契合功能 / 同向参考帧 / 区别于他镜）；**必带运动**（写慢眨眼、呼吸、光效明灭，不写 "completely still"）；运动镜头要交代视角、姿态、轨迹三件事；负面词随题材重审。

**C 实拍口播**：**声音质量 > 画质**。领夹麦优先，小房间少混响，手机录音离嘴 15~20cm；固定机位、眼平高度、正面 45° 光。

**D 剪辑混剪**：素材先按主题/情绪打标签；原声压到 −25dB 以下当底噪，BGM 主导，关键台词处让位（ducking）；二创要有实质改动，纯搬运会被判非原创。

**E 图文轮播**：一页一信息点；正文 ≥40px（1080 宽画布）；6~12 页；首图独立成立（信息流只露这一张）。

### 3.3 人物与考据（跨路径通用，最费时间也最容易返工）

这两块不管你用代码画、AI 生成还是实拍，标准都一样。

**人物四条**：

| 规则 | 反例 | 正例 |
|---|---|---|
| 按身份区分造型 | 皇帝/将军/士兵同一个模子只换颜色 | 君主=冕冠+垂旒+龙纹；将军=盔缨+护肩；士兵=盔+甲；文官=**展脚幞头**+笏板；幼帝=总角双髻；平民=布巾 |
| 手臂三段式 | 一根线从肩连到手，抬起像僵尸；或只画两个圆点当手 | 肩→肘→手两段关节 + 袖身 + 袖口 + 椭圆手掌；后臂在躯干后、前臂在躯干前 |
| 姿态用预设 | 所有"举手"共用一个角度 | `idle` / `raise`（45° 斜上振臂）/ `cup`（折臂持杯）。**直臂上举一律禁止** |
| 全片造型一致 | 两个镜头各画一版，观众看出"换了个人" | 同一角色一套造型，不同镜头只改姿态 |

**状态变化用交叉淡化**：加冕、换装、升格这类时刻，观众要看的是"变了"这个动作——旧形象与新形象同位置按进度交叉透明度，重叠的几帧就是过程。在同一个形象上改颜色只会得到一次突兀跳变。

**考据三条**：

1. **真实地点/器物/服饰，先搜实物参考再画**。凭印象画的历史物件十有八九是错的（兵符画成信、龙椅画成带靠背的椅子、城楼缺中间层）。
2. **地图先列坐标表**：谁在北、谁在南、河在哪、距离多少。方位错了比画得糙更致命。
3. **古制横排自右向左 + 繁体**；匾额在门洞正上方的城墙面，不在城楼上。

⚠️ **看不懂的装饰一律删**。"为了显得华丽"加的红绳、金牌、无出处纹样，观众第一反应是"这是什么意思"，而不是"好看"。

### 3.4 判据

- □ 每个镜头都有素材，没有"待定"
- □ 单镜先看一遍（不要等全片合成才看）
- □ 素材时长 ≥ 分镜时长（宁长勿短，长了能裁，短了没法补）

## 阶段 4 · 剪辑合成

**做什么**：把素材、字幕、音频拼成一条片子。

### 4.1 时间轴对齐（最容易出错的一步）

**单一时间源**：所有层只认同一份时间表，不要各自写死时间。

| 铁律 | 说明 |
|---|---|
| 改时间表后必须重新生成派生文件 | 有些工具读的是编译产物，不读源文件 |
| 镜头时长变了必须重建该镜素材 | 否则旧素材与新时间轴错位 |
| 音画必须等长 | 混流用 `-t <成片时长>` 精确截断，**不加 `-shortest`**（会裁尾帧） |

### 4.2 字幕

- **统一走一个组件**：底部安全区 ~300px + "透明→深色"渐变底板 + 整块上移 ~90px 的 easeOut 淡入（按拍对齐，别逐字弹）
- **主体让位**：正文限制在字幕带之上（横版 **y < 780**）。840 只够避开底板，人物头顶/道具顶端仍会探进字幕带
- **先算单行容量**：中文全角 ≈ 1em，单行字数 ≈ 容器宽 ÷ 字号（留 5% 余量）。超了不报错，只把末尾两三个字挤成孤字行——**只能抽帧看**
- **字数会变的元素要自适应字号**：印章、字牌、标签里放 2~6 个字，字号写死就会"两字撑满、六字溢出"
- **文字可读性**：素材有亮区（人脸/发光物）就加底衬或错位——对比度不在任何自动判据里

### 4.3 音频

**BGM 是账号资产，不要每片现造。** 先看母版有多长，再定内容量：能讲满就用满（母版自带淡出就是天然收尾）；只讲得一半，才退回"截取 + 尾部淡出"。

**成片比母版长，三种做法按优先级**：

| 方案 | 做法 | 何时用 |
|---|---|---|
| **延长剪辑**（首选） | 播到 E（避开尾部淡出）→ 4s **等功率交叉**接到曲中**相似段 S**（频带能量向量余弦相似度，实测可到 0.9998）→ 续播 | 超过母版 1.5 倍，且能测出相似段 |
| 无缝循环 | 裁尾淡出 → 首尾 2~4s **等功率**交叉做环 → 铺满 → 片尾 3s 淡出 | 母版明显短、找不到相似段 |
| ❌ 硬接 | 尾淡出后突然满音量 | 永远别用 |

- **融合时长跟相似度走**：>0.999 时几十毫秒就够，融合越长越像"两段同时在响"；<0.99 才给 2~4s
- **等功率不是可选项**：线性权重在中点掉 ~3dB，听感就是"接点处音量塌一下"
- **验收两条都要看**：接续区 0.5s 窗 RMS 跳变 <4dB **且** 频谱跳变 <1.4× 全片均值。只看总电平发现不了接点
- **音效按画面事件对齐**（与画面共用同一份时间轴），权重约 0.55 叠在 BGM 上，**混完重新过电平判据**
- **电平**：mean ≈ −15dB，峰值留 ≥1dB 余量。触顶就是削波，听感是"炸音"而频谱图上看着还正常

## 阶段 5 · 质检

**做什么**：在交付前把问题拦下来。自动判据抓"硬指标"，人眼抓"观感"。

### 5.1 三道闸门

| 闸门 | 判据 | 时机 |
|---|---|---|
| ① 单镜 | 无报错；排版不压主体；文字与背景亮部对比度够；时序对得上 | 每次改画面 |
| ② 节奏 | **最长连续冻结 ≤3.0s**（全帧平均灰度差 <0.002 记冻结）；静止占比 >45% 需检查 | 合成后 |
| ③ 成片 | 音画时长严丝合缝；关键帧像素特征；音频 mean≈−15dB 且峰值不触顶 | 交付前 |

### 5.2 六项动手检查（自动闸门验不到）

| # | 检查 | 怎么做 | 抓什么 |
|---|---|---|---|
| 1 | **文字重叠审计** | 逐幕列所有文字块 `x/y/宽/高`，**两两求交** | 图例压地名、角标压标题、字幕压人物 |
| 2 | **字幕安全区扫描** | 正则扫源码里 `y/cy/baseY` ∈ [780, 1080] 的元素，逐个判断"背景可进 / 正文必须挪" | 正文探进字幕带 |
| 3 | **元文字排查** | 搜"机制说明 / 行列数 / 单位 / 系列标签 / 制作标注" | 草稿期写给人看的字上了屏 |
| 4 | **空白帧扫描** | 每 ~12s 抽一帧算方差与主色块数 | 漏渲 / 透明层没叠上的全黑或纯色帧（刻意的起幅黑场单列） |
| 5 | **人物一致性核对** | 按角色列出场镜头，比对造型 | 同一角色两种画法、多余的装饰、手臂变圆点 |
| 6 | **抽帧人眼过 2 轮** | 每轮 8~9 帧覆盖全片 | 断字、结构画错、构图难看——**自动判据全抓不到** |

⚠️ **第 1、2 项必须逐幕做，不是修被指出的那一处**。真实教训：用户指出"某一幕字幕压画面"，只修那一幕 → 下一轮又被指出另外三处，同一类问题拖了两轮。

> 完整的返工反推案例（9 类根因 + 用户原话 + 修法）见 [`references/retro-lessons.md`](./references/retro-lessons.md)。**开工前读一遍，能省掉大半返工。**

### 5.3 判据只测"有没有变化"，不测"好不好看"

- 它先下采样（分析尺度常 270px 宽），**柔光呼吸/渐变明暗会被采样抹平**——像素差 <6 灰度，数值上零运动，人眼却觉得"在呼吸"。这是**伪运动**，救不了判据
- 有效的是**画面实体的硬边动作**（旗/火苗/狼烟/人物走动/蒸汽，逐帧位移 ≥2px）、高对比长线条扫过、大面积高幅度位移
- ⚠️ **别用抽象背景粒子凑运动**：推得动判据，但观感廉价，用户会判"背景在飘"。运动要长在**画面里存在的东西**上
- **通过 ≠ 观感好**（花哨廉价的运动也能过）；**不通过 ≠ 难看**（收尾定格本该静）
- **人眼必须过 2 轮**，每轮抽 8~9 帧覆盖全片：自动判据抓不到"断字 / 结构画错 / 构图难看"

**正确用法**：用判据发现漏掉的死角，不是刷分。发现后先问"为什么这么久没变化"——答案通常是**镜头太长**或**素材本身静态**，要改结构而非加特效。

## 阶段 6 · 交付

**做什么**：准备成片、封面、文案三样东西。

### 6.1 成片规格

| 项 | 要求 |
|---|---|
| 画幅 | 按投放平台定（竖版 9:16 / 横版 16:9），**换画幅不是缩放，是重排版式** |
| 帧率 | 全片统一，素材层与覆盖层一致 |
| 码率 | 平台上传建议 ≥8Mbps（1080p），太低会被二次压缩糊掉 |
| 命名 | 片子名 + 版本，别用 `final_final` |

### 6.2 封面

| 项 | 做法 | 为什么 |
|---|---|---|
| 平台规格 | 抖音要**两套**：横封面 **4:3**（1440×1080，信息流）+ 竖封面 **3:4**（1080×1440，主页）；成片的 16:9 两处都用不上 | 拿 16:9 上传，平台自动裁左右，标题常被切一半 |
| 底图来源 | 从**素材层**抽帧，不从成片抽 | 成片已烧入字幕，抽帧带文字残影 |
| 主视觉 | **一眼能辨认是什么**；缩小到 200px 宽还认得出 | 信息流里就是这个尺寸 |
| 光效 | 同心细环 + 径向柔光 | 粗放射条在深底上叠出灰褐色，像玻璃裂纹 |
| 版式 | 参数化（宽高走参数），一套模板渲多尺寸 | 各平台各做一版必然逐渐不一致 |

### 6.3 文案

- **标题**：能独立成立，不依赖画面。控制在平台上限内（抖音 30 字），别被截断
- **简介**：第一段就是钩子（很多人只看这一行）；结尾放「愿你」式收束
- **话题**：平台上限 5 个，文案阶段就控制住，别到发布时被拦
- **AI 标注**：画面含 AI 生成内容就标注——只勾"原创"不标注有限流/下架风险

## 阶段 7 · 发布与复盘

**做什么**：发出去，然后读对的数据。

### 7.1 发布

平台对个人**没有开放的内容发布 API**，只能走网页。半自动的边界很清楚：**机械的复制粘贴交给脚本，身份与发布权留给人**。

| 环节 | 谁做 |
|---|---|
| 登录（扫码） | 人 |
| 上传视频 / 标题 / 简介 / 话题 | 脚本 |
| 封面（上传 + 保存） | 脚本，但**保存必须真实点击** |
| 自主声明、合集 | 人 |
| **点发布** | **人** |

**六个必知的坑**：

1. 扫码后跳首页，找不到上传控件 → 重新打开上传页
2. 等页面用 `networkidle`，`domcontentloaded` 太早
3. **话题上限 5 个**，超了会弹提示卡发布
4. **脚本退出会关掉浏览器**，填好的表单全丢 → 结尾让进程常驻
5. **封面「保存」用合成事件会静默失败**（弹窗关了，但封面存成视频首帧黑场，且不报错）→ 必须用真实点击
6. **话题写成纯文本不转标签** → 必须键盘输入触发下拉，再点选匹配项

### 7.2 复盘：看「2 秒跳出率」，不看播放量

**播放量由推荐量决定，不是内容质量的信号。** 该看留存曲线最左端：

| 指标 | 用途 |
|---|---|
| **2 秒跳出率** | 最早最灵敏，只反映"封面承诺 + 第一帧"是否成立 |
| 5 秒完播率 | 反映钩子，但滞后 |
| 完播率 | 60s 以上意义有限 |

实测基线 **45~50%**（一半人两秒内走）。判据：改版后 **<30%** 说明钩子改造有效；仍在 45% 左右 → 问题在选题或封面承诺，不在画面。

**发布后等 2 小时再读**，冷启动前 30 分钟波动极大。

| 阶段 | 判据 | 阈值 |
|---|---|---|
| 选题 | 四问全过 | — |
| 脚本 | 念一遍计时误差 | ±10% |
| 分镜 | 单镜时长 | ≤12s |
| 分镜 | 时长求和 | 精确等于成片时长 |
| 素材 | 素材时长 ≥ 分镜时长 | 宁长勿短 |
| 字幕 | 正文位置 | y < 780（横版） |
| 字幕 | 单行字数 | ≤ 容器宽 ÷ 字号 |
| 音频 | 电平 | mean ≈ −15dB，峰值留 ≥1dB |
| 音频 | 接续点 RMS 跳变 | <4dB |
| 质检 | 最长连续冻结 | ≤3.0s |
| 质检 | 静止占比 | <45% |
| 交付 | 封面主视觉 | 200px 宽仍可辨 |
| 发布 | 2 秒跳出率 | 目标 <30% |

## 附 B · 高频错误

| 症状 | 根因 | 修法 |
|---|---|---|
| 开头 3 秒留不住人 | 先铺垫再给结论 | 结论前置，第 0 帧给反直觉 |
| 字幕压画面主体 | 逐镜手摆，没有统一安全区 | 统一组件 + 主体 y<780 |
| 长句末尾两三个字单独成行 | 字数×字号 > 容器宽，超了不报错只折行 | 降一级字号或拆句 |
| 文字压亮部看不清，自动判据全过 | 对比度不在任何判据里 | 排版前看背景亮度，亮区加底衬 |
| 加一堆小动效，静止判据只降 2% | 判据算全画面平均差，小元素贡献极小 | 用大面积/高对比；或改镜头长度 |
| 柔光呼吸加了没效果 | 下采样后软过渡被抹平，是伪运动 | 用画面实体的硬边动作 |
| 17s 镜头怎么加动效都闷 | 镜头太长 + 素材静态 | >12s 必须配持续事件，或缩短 |
| 循环 BGM 接点"断一下" | 硬接母版，尾淡出后突然满音量 | 延长剪辑或等功率环 |
| 接点仍"塌一下" | 交叉淡化用线性权重，中点掉 3dB | 等功率曲线 |
| 加了音效后成片削波 | 只验 BGM 电平 | 混完重新过电平判据 |
| 封面上的字与底图上的字叠在一起 | 底图从成片抽帧 | 只从素材层抽 |
| 发布后被判非原创/限流 | AI 画面只勾"原创"没标 AI | 按平台要求标注 |
| 填好的表单突然全丢 | 脚本进程退出，浏览器一起关 | 让进程常驻 |
| 数据看着很差但刚发布 | 冷启动前 30 分钟波动极大 | 等 2 小时看 2 秒跳出率 |

## 附 C · 设计阶段自查（9 类根因）

> 这 9 类来自一支 213 秒片子的 **7 轮返工、近百条修改**。共同点：**都不是"不会做"，而是"没想到要做"**。
> 所以只能靠清单防。**开工前读一遍，每类问自己一句。**

| # | 类别 | 开工前问自己 | 典型错误 |
|---|---|---|---|
| 1 | **叙事画面化** | 每条字幕，画面里有没有具体的东西在承载它？ | 抽象名词直接当字幕；比喻句没有单独镜头 → 变成 PPT 配图 |
| 2 | **字幕三件事** | 出现方式是上移淡入吗？安全区够吗？逐幕查过重叠吗？ | 位移量太小像"挪了一下"；只修被指出的那一处 |
| 3 | **人物** | 同一角色全片造型一致吗？手臂是三段式吗？姿态是预设吗？ | 手臂一根线 + 圆点手；直臂上举；两个镜头两种画法；多余装饰 |
| 4 | **考据** | 真实地点/器物/服饰，搜过实物参考吗？ | 地图方位错、城楼缺层、匾额现代横排、兵符画成信、龙椅凭印象 |
| 5 | **动效语义** | 这个动的是画面里的什么东西？起点绑事件帧了吗？ | 背景粒子凑运动；涟漪在插入前就泛起；半径不出屏 |
| 6 | **图表** | 这行字是给观众看的，还是给我自己看的？同类元素尺寸同源吗？ | "一格=一年""20 列 16 行"上了屏；两侧格子大小不一 |
| 7 | **节奏** | 镜头尾部还有新信息吗？幕间有纯过渡空镜吗？ | 讲完不收；动作结束不切镜；死完五人到下一幕空 40 帧 |
| 8 | **音乐** | 接续点避开前奏/尾奏了吗？是等功率吗？ | 硬接、线性交叉、循环点落在淡入段 |
| 9 | **文案误读** | 收尾句念给外人听，他会理解成什么？ | 比喻太隐晦（"愿你手里的每一件黄袍"会被读成鼓励造反） |

**优先级**：第 3、4 类最费时间也最容易返工（人物与考据每错一次要重渲全片），第 1 类最容易被忽略（影响也最大）。
