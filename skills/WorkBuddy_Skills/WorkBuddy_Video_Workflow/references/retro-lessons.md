# 返工反推清单 · 从真实修改反推设计检查项

> 来源：一支 213 秒 / 21 幕的历史科普片，**用户提了 7 轮意见、近百条具体修改**。
> 这份文件把"被退回的问题"按**根因**归类，每条给出「用户原话 → 为什么第一版会错 → 设计时该问什么 → 修法」。
>
> 用法：**开工前读一遍第 1–9 类**（设计阶段就能避开的），**出片前过一遍第 10 类**（必须动手验的）。
> 这里的问题不是"技术 bug"，是"做的时候根本没想到"——所以它们只能靠清单防，不能靠经验防。

---

## 核心结论

**7 轮返工里，5 轮花在"画面做糙了"，只有 2 轮在改内容结构。**

| 轮次 | 主要内容 | 性质 |
|---|---|---|
| 第 1 轮 | 选题太敏感 | 红线 |
| 第 2 轮 | 视觉风格太丑（扁平简笔） | 风格基线 |
| 第 3 轮 | 结构要改成"四问拆解" | **内容** |
| 第 4 轮 | 字幕方式、场景考据、人物、动效语义 | **画面** |
| 第 5 轮 | 文字重叠、地理错误、人物粗糙、音乐 | **画面** |
| 第 6 轮 | 人物重绘、城门透视、蒙版、酒宴 | **画面** |
| 第 7 轮 | 手臂、形象一致、匾额、音乐 | **画面** |

**推论：第一版就要把「人物、字幕、考据」做对。** 这三样每错一次，就要重渲全片（这支片 5112 帧，一轮约 8 分钟渲染 + 复核）。

## 一、叙事：每个论点必须有画面

| 用户原话 | 为什么第一版会错 | 设计时该问 |
|---|---|---|
| 「条件分析这里，每一条都按照我说的这种，你再单独做一个画面，增加形象化」 | 分析类内容容易写成"字幕条 + 背景"，以为文字说清就够了 | **每条字幕，画面里有没有一个具体的东西在承载它？** |
| 「只差有人去拧，我们应该使用单独的画面去做一个形象的体现」 | 比喻句只写在文案里，画面还是上一个镜头的延续 | 比喻句要不要单独一镜？ |
| 「每个条件都要有画面支撑」（重复强调两次） | 分镜表按"讲什么"排，没按"看到什么"排 | 分镜表加一列「画面承载物」，空着的就是不合格 |
| 「时机这里也要画主少国疑的画面，权力真空的画面」 | 抽象概念直接当字幕，没落地成场景 | 抽象名词 → 具体场景（空龙椅 / 幼帝 / 大臣窃语） |

**检查项**：分镜表逐行问「这一镜观众看到的是什么？」。答"字幕"或"上一镜的画面"→ 不合格。

## 二、字幕：出现方式 + 安全区 + 不遮挡

| 用户原话 | 为什么第一版会错 | 修法 |
|---|---|---|
| 「字幕的动效应该是上移淡入之类的，现在是直接往上移动了一点，这不合理」 | 位移量太小（十几 px），看起来像"挪了一下"而不是"入场" | 上移 **90px** + `easeOut` + 透明度 0→1，三者同时 |
| 「普遍存在字幕和画面重叠遮挡的问题」 | 画面按"构图好看"排，没给字幕留带 | 正文 **y < 780**；840 只够避开底板 |
| 「大军北上夜宿陈桥驿，字幕和图像重叠了，盖住了，视频所有地方都要检查修改」 | 只修了被指出的那一处 | **逐幕扫描**，不是修一处 |
| 「柴荣病逝这一页也是，字幕只向上移动了一点点」 | 同一个组件，但位移参数被别处覆盖 | 字幕统一组件，参数只在一处 |

**检查项**（出片前必做）：

1. 正则扫源码里所有 `y / cy / baseY` 落在 780–1080 的元素，逐个判断"背景可进 / 正文必须挪"
2. 逐幕列出所有文字块的 `x/y/宽/高`，**两两求交**，输出重叠报告
3. 抽帧看 3 处：字幕刚出现那一帧、字幕稳定那一帧、字幕消失前那一帧

## 三、人物：造型、结构、一致性

| 用户原话 | 为什么第一版会错 | 修法 |
|---|---|---|
| 「所有人物手和胳膊都变成了两个圆点」 | 手臂用一根线 + 圆点手，抬起来就只剩两个点 | **三段式**：肩→肘→手两段关节 + 袖身（宽于手臂）+ 袖口 + 椭圆手掌 |
| 「人物的手臂设计还是很奇怪，为什么不画出来手臂呢」 | 同上，改了一次还是不够 | 后臂画在躯干之后、前臂在之前，任何姿势都能看出结构 |
| 「不要做那个类似僵尸的动作，不要做那个把手抬起来的动作」 | 直臂上举是"举手"的默认画法 | 用姿态预设：`raise` 是 **45° 斜上振臂**，`cup` 是折臂持杯 |
| 「1:17 的形象要比 1:23 的形象好很多，两个应该换过来」 | 两个镜头各自画了主角，造型不一致 | **同一角色全片一个造型**，不同镜头只改姿态不改形 |
| 「黄袍加身前后的任务可以从原来的将军形象过渡到黄袍形象」 | 在一个形象上改颜色/配饰，得到突兀跳变 | **两个形象交叉淡化**，重叠的几帧就是"加身"的过程 |
| 「脖子上挂了红绳挂了金牌我不明白什么意思」 | 为了"显得华丽"加了装饰，但无出处 | 配饰必须有历史依据，看不懂的装饰一律删 |
| 「人物画得太粗糙了，平民、士兵、将军、君主、柴荣、幼帝、赵匡胤等等身份和人物应该有精致一点的形象」 | 一套通用小人只换颜色 | **身份化造型**：冕冠/盔缨/展脚幞头/总角/布巾，各不同 |
| 「1:50 五个皇帝穿的衣服也不像龙袍」 | 龙袍画成了纯色长袍 | 龙袍要有：交领右衽、团龙纹、腰带、宽袖 |

**检查项**：全片人物按角色列一张表——每个角色出现在哪几镜、造型是否一致、有没有多余的装饰。

## 四、场景考据：错了比糙了更致命

| 用户原话 | 为什么第一版会错 | 修法 |
|---|---|---|
| 「高平之战你画的像是在黄河边，要确认各个地理位置的相对正确性」 | 地图按"好看"排，没核对真实方位 | 画地图前先列**坐标表**（谁在北、谁在南、河在哪） |
| 「高平之战的形式你没有表现出来，尤其是如何包围的」 | 只画了箭头，没画包围关系 | 包围要画**包围圈 + 围点 + 合围标注** |
| 「开封的城楼你把屋顶直接放在了城墙上，重画」 | 缺中间层（城台、楼身、额枋） | 城楼五层：城墙 → 城台 → 楼身 → 出檐 → 屋脊 |
| 「开封两个字应该在城门的上方城墙上而不应该在上面的城楼上」 | 匾额位置凭印象放 | 匾额在**门洞正上方的城墙面** |
| 「开封应该使用繁体字，自右向左写」 | 用了现代横排 | 古制横排**自右向左** + 繁体 |
| 「点检作天子的文字和木牌不对齐，应该放在木牌上显示文字」 | 文字和牌子是两个独立图层 | 文字与牌子**同组变换**，刻在牌面正中 |
| 「兵符，兵符不是一封信」 | 凭"符"字想象成了文书 | 查实物：虎形、中缝可对半、刻铭文 |
| 「龙椅画的不对，你去搜一下，参考一下龙椅的样式」 | 凭印象画了把"带靠背的椅子" | 查实物：圈椅式椅背 + 双龙戏珠 + 须弥座 + 脚踏 + 屏风 |
| 「文官治国应该使用宋朝文官标志性的帽子」 | 用了通用官帽 | 宋代文官 = **展脚幞头**（两侧长翅） |
| 「三角形代表的应该是帐篷，可以画的更像帐篷一点」 | 一个三角形当帐篷 | 帐篷要有：布幔褶皱、脊杆、立柱、掀开的门帘 |
| 「城门应该画的更豪华一点，毕竟是开封的城门」 | 按"够用"画，没考虑场景重要性 | 重要场景（都城/宫殿）要多花 2~3 倍细节 |

**检查项**：凡涉及**真实地点 / 真实器物 / 真实服饰**，先搜一次实物参考图，再画。**凭印象画的历史物件，十有八九是错的。**

## 五、动效：要实体动作，不要背景特效

| 用户原话 | 为什么第一版会错 | 修法 |
|---|---|---|
| 「我说增加动效，不是让你把整个视频的背景上都增加一些点点，在那里动，不是这种动效，而是应该增加人物、物品、事物的动作」 | 加粒子最省事，且能骗过"静止判据" | 动效必须长在**画面里存在的东西**上：旗、火、烟、马、人、灯 |
| 「插钥匙这一幕，钥匙没插入的时候不要闪动涟漪，插入之后开始缓慢优雅的泛起涟漪」 | 涟漪起点绑"镜头起点" | 绑**事件完成帧**（钥匙到位那一帧） |
| 「圆圈要扩大到整个屏幕，直到出屏幕」 | 半径凭目测 | 半径 ≥ **屏幕半对角线**（1080p 约 1100px）+ `easeOut` |
| 「钥匙和一些线条有重叠穿模」 | 绘制顺序没理清 | 分层：底层先画 → 钥匙 → 遮挡层 → 锁孔 |
| 「钥匙插在锁上还是做的不行，可以把上面的蒙版做成左右两个部分，左蒙版在钥匙下面，右蒙版在钥匙上面」 | 用 mask 挖洞，做不出"被挡住" | **左右分蒙版**：左半在钥匙下、右半在钥匙上 |
| 「城门开了，但是那些黄色的点没有随着城门移动」 | 门钉和门扇是两个图层 | 门钉并进**门扇组**，随门一起变换 |
| 「门是向内开的，原点不能在三维空间以门轴为中心旋转」 | 只做了水平缩放，像推拉门 | 门扇绕**铰链轴**旋转，投影宽度按 `cos` 收缩 |
| 「后面钥匙在锁上转动的动画去掉」 | 加了"看起来合理"但没必要的动作 | 动作只保留有信息量的 |
| 「右下角的六个人在抽出，循环移动，很奇怪」 | 用循环位移表示"人多" | 改成**静止的驻扎场景**（帐篷/篝火/歇息） |
| 「收精兵这里速度太快，人物跳动太快了，应该是慢慢的向右跳进禁军然后消失」 | 循环速度按"能看出在动"给 | 速度按**信息可读性**给，且方向必须对 |

**检查项**：每个动效问一句「这个动的是画面里的什么东西？」答"背景粒子/光斑"→ 换掉。

## 六、图表：别把"给人看的说明"做到画面里

| 用户原话 | 为什么第一版会错 | 修法 |
|---|---|---|
| 「一格等于一年这种文字是我发给你让你知道的，不是让你做到视频里以文字形式呈现的」 | 把需求说明当成了画面元素 | **元文字不上屏**：机制说明、行列数、单位换算，都是给人看的 |
| 「同样的问题需要检查每个画面，还有 20 列 16 行，这些文字不应该出现在画面上」 | 只删了被指出的那处 | 出片前**搜元文字**逐条确认 |
| 「两边的小方格的大小要保持一致」 | 两侧独立排版，各算各的 | 同类元素**尺寸必须同源**（同一个 cell 常量） |
| 「采用一年一个格子的方式，不要做那个类似魂环检查的东西，有个框在所有格子上来回移动，很奇怪」 | 加了"扫描框"表示进度，但语义不明 | 图表上的动画元素必须有明确语义 |
| 「矩阵的形式，通过不同的颜色代表不同的朝代，同一个朝代内的皇帝采用同一种颜色的不同具体饱和度」 | 用了随机配色 | 配色要有**语义编码**（朝代=色相，在位时长=明度） |
| 「横向扫描的这个黄色的条带，明显是错误的」 | 为了"动起来"加了无意义元素 | 无信息量的装饰一律删 |

**检查项**：图表类画面，逐个文字问「这是给观众看的，还是给我自己看的？」

## 七、节奏：空镜与静止

| 用户原话 | 为什么第一版会错 | 修法 |
|---|---|---|
| 「天亮了黄袍加身，后面又有很长一段静止空镜，才到下一个镜头」 | 镜头长度按"讲完"定，没按"画面撑得住"定 | 镜头尾部没有新信息就剪掉 |
| 「到 1:51 士兵和字幕才出现，中间的空镜太长了」 | 上一个动作结束后没立刻接下一镜 | 动作结束 = 切镜点 |
| 「五个人都死掉之后，接下面的视频内容，这里五个人出完之后，到下面的军队形象出现，中间隔了很久的时间间隔空镜」 | 五帝死完到下一幕有 40+ 帧空白 | 一幕结束立刻进下一幕，不留过渡空镜 |
| 「1:17 的形象…腿也在莫名奇妙的晃动」 | `walk` 参数没传，但代码仍按帧算摆动 | **不传就不该动**（`undefined` 要短路） |

**检查项**：全片看一遍"镜头切换处有没有超过 0.5 秒的纯过渡"。

## 八、音乐：循环的天然缺陷

| 用户原话 | 为什么第一版会错 | 修法 |
|---|---|---|
| 「BGM 放完之后，重新进入循环，这里你处理的不好，我需要的无限循环直到视频结尾」 | 用 `-stream_loop` 硬接 | 做无缝环（裁尾淡出 + 等功率交叉） |
| 「2:17 这里上一段音乐的结束和下一段的开始太明显了」 | 线性交叉，中点掉 3dB | **等功率**（`sqrt`）曲线 |
| 「背景音还是衔接不好，你需要去学习专用的音乐剪辑 skill，找到音乐相似的点，进行融合拼接」 | 在"循环"上打补丁，没换方法 | **延长剪辑**：播到 E → 找相似段 S → 4s 等功率接续 |
| 「1:56 左右还是能听出来音乐切换的感觉」 | 循环点落在前奏淡入段 | 循环/接续点必须避开前奏与尾奏 |

**检查项**：接续点 0.5s 窗 RMS 跳变 <4dB **且** 频谱跳变 <1.4× 全片均值。两条都过才算完。

## 九、文案：避免误读

| 用户原话 | 为什么第一版会错 | 修法 |
|---|---|---|
| 「最后愿你手里的每一件黄袍，这里是不是太隐晦了，很容易让用户误读为鼓励造反」 | 比喻句只想着"美"，没想"会被怎么读" | 收尾句**必须能一眼读出善意**，不能留解释空间 |
| 「关注我，每天一个历史真相，这句去掉」 | 模板化 CTA | 结尾只留内容本身，不硬塞关注语 |
| 「3:29 第一集一件黄袍这句话也去掉」 | 系列标签默认要有 | 平台不需要就不加 |

**检查项**：收尾句念给一个不了解背景的人听，问他"你觉得这句话在鼓励什么"。

## 十、出片前必做的 6 项动手检查

| # | 检查 | 怎么做 | 抓什么 |
|---|---|---|---|
| 1 | **文字重叠审计** | 逐幕列所有文字块 `x/y/宽/高`，两两求交 | 图例压地名、角标压标题、字幕压人物 |
| 2 | **字幕安全区扫描** | 正则扫 `y/cy/baseY` ∈ [780, 1080] 的元素 | 正文探进字幕带 |
| 3 | **元文字排查** | 搜"机制说明/行列数/单位/系列标签/制作标注" | 草稿文字上了屏 |
| 4 | **空白帧扫描** | 每 12s 抽一帧算方差与主色块数 | 漏渲、透明层没叠上 |
| 5 | **人物一致性核对** | 按角色列出场镜头，比对造型 | 同一角色两种画法 |
| 6 | **抽帧人眼过 2 轮** | 每轮 8~9 帧覆盖全片 | 断字、结构画错、构图难看——自动判据全抓不到 |

**用户原话**：「你需要逐帧检查，不要偷懒，还有就是做完了自己记得检查一遍」。

---

## 一句话总结

> **这些问题的共同点：都不是"不会做"，而是"没想到要做"。**
> 所以防它们的唯一办法是把它们变成**清单上的勾**，而不是指望下次记得。
